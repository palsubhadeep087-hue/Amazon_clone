# Amazon Clone

A simple Amazon homepage clone built using HTML and CSS.
This project was created to practice frontend development, webpage structure, styling, layouts, and responsive design.

## Features

* Amazon-inspired homepage design
* Navigation bar with Amazon-style layout
* Search bar
* Product categories
* Product boxes and images
* Hero/banner section
* Footer section
* Clean HTML and CSS structure

## Technologies Used

* HTML
* CSS
